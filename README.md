## Параметры задач
Параметры задачи задаются методом `SetParameter` (в Globalizer — ключами командной
строки `-Имя значение`), их список и текущие значения возвращает `GetParameters`.

`rastriginInt` — функция Растригина с непрерывными и дискретными параметрами:

| Параметр | Значение | По умолчанию |
|---|---|---|
| `ContinuousVariables` | число непрерывных параметров, не меньше 1 | 1 |
| `DiscreteVariables` | число дискретных параметров, не меньше 0 | 1 |
| `DiscreteValues` | число значений каждого дискретного параметра (`A`, `B`, …), от 2 до 26 | 2 |

Размерность равна `ContinuousVariables + DiscreteVariables` (не больше 100).
`SetDimension` (ключ `-N`) сохраняет явно заданное число: если задано только
`DiscreteVariables`, меняется число непрерывных параметров, иначе — дискретных;
если заданы оба, другую размерность задать нельзя. Пример:

```
GlobalizerMain -lib librastriginInt.dll -ContinuousVariables 3 -DiscreteVariables 2 -DiscreteValues 4
```

Минимум — в нуле по непрерывным параметрам и в последнем значении по дискретным.
