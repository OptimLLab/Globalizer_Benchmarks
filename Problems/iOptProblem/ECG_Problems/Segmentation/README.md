# Сегментация сигналов ЭКГ: оптимизация гиперпараметров нейросетевой модели

## Описание задачи

Сегментацией в кардиологии называют выделение в ЭКГ-сигнале всех элементов кардиоциклов, соответствующих **сокращению предсердий, желудочков и восстановлению миокарда**. Точная локализация элементов кардиоциклов позволит однозначно определить нозологию, описанную в медицинской литературе, что позволит разработчику написать аналитический алгоритм.

Сегментация сигнала ЭКГ является нетривиальной задачей из-за существования низкоамплитудных зубцов, описывающих работу сердечной мышцы, вследствие чего интерпретация сигнала затрудняется и приводит к ошибочной диагностике.

Наиболее эффективный способ сегментации ЭКГ-сигналов — применение нейронных сетей, изначально специализированных на сегментации изображений. Однако обучение таких моделей осложнено наличием гиперпараметров, для которых требуется точная настройка.

Решается задача **покомпонентной разметки (segmentation / sequence labeling)** одномерного сигнала. Целевые классы: **фон (0), комплекс QRS (1), T-волна (2), P-волна (3)**.

## Данные

Исходные данные представляют собой набор JSON-файлов, где каждый сигнал описывается двумя файлами:
- файл с метаинформацией о записи;
- файл с сигналом и временными метками комплексов.

При формировании датасета использовалось **680 сигналов ЭКГ**, локализацию сегментов в которых осуществляли врачи-функционалисты, разрабатывающие первую версию базы данных **Lobachevsky University Electrocardiography Database (LUDB)**.

### Основные шаги подготовки датасета

1. **Чтение сигнала.** Для каждой записи считывается сигнал размера `[число сэмплов окна, число входных каналов]`.
2. **Построение меток по каждому каналу.** Для каждого канала отдельно считывается соответствующий файл аннотаций.
3. **Перевод аннотаций в покомпонентный вектор меток** числа сэмплов окна. Общий словарь классов: фон = 0, остальные классы нумеруются с 1.
4. **Обрезка неразмеченных участков** с начала и конца. Если после обрезки длина записи меньше размера окна, запись исключается.
5. **Нарезка на окна с перекрытием.** Сигнал разбивается на окна длиной `W` с заданным перекрытием.

Длина исходной записи — порядка **5000 отсчётов**. Перед нарезкой выполняется обрезка краёв в **450 отсчётов** с начала и конца записи, что позволяет исключить неразмеченные участки и оставить для обучения центральную часть сигнала. Далее сигнал разбивается на окна фиксированной длины по **500 сэмплов** — размер подбирался так, чтобы в одном примере целиком присутствовал по меньшей мере один кардиоцикл вместе с его морфологическими компонентами (зубцы P, QRS, T с учётом контекста).

Для повышения устойчивости разметки на границах окон применяется **перекрытие 64 отсчёта**. Один и тот же временной участок присутствует как минимум в двух соседних примерах, что повышает стабильность обучения и снижает чувствительность модели к «краевым» эффектам при сегментации.

## Архитектура нейронной сети

Для решения задачи покомпонентной разметки одномерного сигнала используется архитектура **U-Net 1D**.

### Вход и выход

- Вход: тензор ЭКГ-сигнала `x ∈ R^{B × C_in × T}`, где `B` — размер пакета, `C_in` — число входных каналов (ЭКГ-отведений), `T` — размер окна в отсчётах.
- Выход: логиты классов `logits ∈ R^{B × C_cls × T}`, где `C_cls` — число классов сегментации (фон / P / QRS / T). К логитам применяется softmax для получения вероятностей классов по каждому временному отсчёту `t`.

Во всех реализациях используются одномерные свёртки с ядром `k = 3` и padding = 1, одномерная пакетная нормализация и нелинейность ReLU.

### Принцип U-Net

Энкодер уменьшает временное разрешение (downsampling) и увеличивает число каналов; декодер восстанавливает временное разрешение (upsampling) и объединяет признаки с соответствующих уровней энкодера через **skip-соединения**.

- **Downsampling:** `MaxPool1d(2)` — длина последовательности уменьшается в 2 раза: `T → T/2`. После субдискретизации выполняется свёрточная обработка признаков.
- **Upsampling:** `ConvTranspose1d(k=2, s=2)` — размер данных увеличивается в 2 раза: `T → 2T`. Из-за возможных несовпадений пространственной размерности между тензором после повышения дискретизации и тензором skip-соединения применяется **симметричный паддинг** для корректной конкатенации: `x = cat[x_skip, x_up]` по оси каналов ЭКГ-сигнала.

### Структура блоков

**DoubleConv1D** (базовый блок энкодера и декодера):
DoubleConv(x) = ReLU(BN(Conv_3(x))) → ReLU(BN(Conv_3(·)))

где `Conv_3(·)` — одномерная свёртка с ядром 3; `BN(·)` — пакетная нормализация; `ReLU(·)` — функция активации.

**Down1D:**
Down(x) = DoubleConv(MaxPool(x))

**Up1D:**
Up(x_low, x_skip) = DoubleConv(cat[x_skip, UpConv(x_low)])

### Число каналов по уровням

Пусть `F_0` — число базовых фильтров. Тогда число каналов по уровням U-Net: `F_0, 2F_0, 4F_0, 8F_0, 16F_0`.

### Encoder
x_1 = DoubleConv(x) ∈ R^{B × F_0 × T}
x_2 = Down(x_1) ∈ R^{B × 2F_0 × T/2}
x_3 = Down(x_2) ∈ R^{B × 4F_0 × T/4}
x_4 = Down(x_3) ∈ R^{B × 8F_0 × T/8}
x_5 = Down(x_4) ∈ R^{B × 16F_0 × T/16}


### Bottleneck
x_b = DoubleConv(x_5) ∈ R^{B × 16F_0 × T/16}

Содержит наиболее контекстную информацию.

### Decoder
x = Up(x_b, x_4) ∈ R^{B × 8F_0 × T/8}
x = Up(x, x_3) ∈ R^{B × 4F_0 × T/4}
x = Up(x, x_2) ∈ R^{B × 2F_0 × T/2}
x = Up(x, x_1) ∈ R^{B × F_0 × T}

### Выход сети

Финальная свёртка 1×1 для линейной классификации каждого временного отсчёта:
logits = Conv_1(x) ∈ R^{B × C_cls × T}

### Иерархическое извлечение признаков

На глубоких уровнях энкодера благодаря последовательному уменьшению пространственного разрешения и расширению рецептивного поля формируются признаки, обобщающие контекст на протяжённых временных интервалах. Skip-соединения передают активации с соответствующих уровней энкодера на соответствующие уровни декодера, обеспечивая доступность пространственно-временной информации, необходимой для локализации границ сегментов кардиоцикла.

## Обучение

- Фреймворк: **PyTorch**.
- Число эпох обучения при одном испытании оптимизации: **40** с вычислением метрики качества.

## Метрика качества

Для каждого класса `c` вычисляются precision и recall:
Precision_c = TP_c / (TP_c + FP_c)
Recall_c = TP_c / (TP_c + FN_c)


Затем F1-мера:
F1_c = 2 · Precision_c · Recall_c / (Precision_c + Recall_c)

где `TP_c, FP_c, FN_c` — число истинно-положительных, ложноположительных и ложноотрицательных предсказаний класса `c`, подсчитанных по всем отсчётам времени `t` на всей выборке.

Макро-усреднённая F1-мера рассчитывается по **точному совпадению меток на каждом отсчёте (без временного допуска)**. Итоговая метрика для сравнения моделей — среднее по классам без фона:
F1_macro = (1 / (C_cls − 1)) · Σ_{c=1}^{C_cls−1} F1_c


## Оптимизация гиперпараметров

Задача настройки гиперпараметров — задача поиска глобального оптимума целевой метрики качества. Целевая функция многоэкстремальная, задана в виде «чёрного ящика», однократное вычисление требует значительных вычислительных ресурсов (обучение модели сегментации требует больше времени вследствие большей глубины сети и большего объёма обрабатываемых данных).

### Варьируемые гиперпараметры

| Гиперпараметр | Диапазон |
|---|---|
| Вероятность отключения нейронов (Dropout) | `p ∈ [0.0, 1.0]` |
| Количество уровней энкодера/декодера (глубина) | `depth ∈ [3, 5]` |

Изменение глубины позволяет параметрически менять архитектуру сети и, как следствие, количество обучаемых параметров. Dropout используется для регуляризации и предотвращения переобучения.

### Инструмент оптимизации: система Globalizer

Применён **информационно-статистический алгоритм глобального поиска**, реализованный в системе **Globalizer** (https://github.com/OptimLLab/Globalizer), принадлежащий классу методов липшицевой глобальной оптимизации.

Алгоритм основан на предположении липшицевости целевой функции и использует редукцию размерности с помощью кривых Пеано для сведения многомерной задачи к одномерной. Ключевое преимущество — **детерминированность**, обеспечивающая воспроизводимость результатов и гарантированную сходимость к глобальному минимуму при выполнении определённых условий.

### Параметры запуска алгоритма глобального поиска

| Параметр | Значение |
|---|---|
| Параметр надёжности `r` | 10 |
| Точность глобального поиска `ε` | 10⁻² |
| Максимальное число поисковых испытаний `Kmax` | 320 |
| Плотность построения развёртки `m` | 10 |

### Параллельные схемы

Реализованы синхронная и асинхронная схемы распараллеливания по принципу «мастер-рабочие». Использовалось число MPI-процессов: **1, 3, 5, 9, 17, 33**.

- **Синхронная схема** — переход к следующей итерации только после завершения всех `p` испытаний текущей итерации.
- **Асинхронная схема** — новая точка отправляется на вычисление сразу после получения результата от любого рабочего процесса, что минимизирует простои вычислительных ресурсов.

## Результаты экспериментов

Вычислительные эксперименты проводились на узле суперкомпьютера «Лобачевский»:
- ОС Linux CentOS 8.2;
- 2 процессора Intel Xeon Platinum 8558 2.1/4GHz (48 ядер каждый);
- ОЗУ 2048 Gb;
- 8 графических ускорителей Nvidia RTX PRO 6000;
- Компилятор Intel C++ Compiler 2023 с поддержкой OpenMP, Python 3.12, PyTorch.

При ограничении `Kmax = 320` длительность последовательного запуска: **5.5 часов**.

### Итоговый результат

Достигнуто значение целевой метрики **F1-macro = 0.80**. При 17 процессах ускорение составило **15.68** относительно последовательного запуска.

## Роль оптимизации в диагностической задаче

Методы поиска глобального экстремума служат инструментом обеспечения стабильной и воспроизводимой работы модели в условиях ограниченных вычислительных ресурсов. Для задачи сегментации основной целью является **точная локализация морфологических элементов кардиоцикла** для последующего расчёта интервалов. В данном контексте подбор гиперпараметров сегментационной сети обеспечивает устойчивое выделение границ комплексов, что напрямую влияет на надёжность последующей интерпретации.

## Выводы

- Асинхронная схема распараллеливания в системе Globalizer показала более высокую эффективность по сравнению с синхронной, особенно при увеличении числа процессов.
- Детерминированные методы липшицевой глобальной оптимизации перспективны для точной настройки гиперпараметров глубоких нейронных сетей в медицинских диагностических задачах.
- Асинхронный алгоритм глобальной оптимизации, реализованный в системе Globalizer, является эффективным инструментом настройки гиперпараметров нейронных сетей для задач медицинской диагностики.
