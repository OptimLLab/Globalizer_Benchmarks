# Классификация сигналов ЭКГ: оптимизация гиперпараметров нейросетевой модели

## Описание задачи

Задача классификации в контексте машинного обучения сводится к отнесению исследуемого объекта к одному из заранее известных классов или категорий. В рамках данной работы решается задача **мультиклассовой классификации** сигналов ЭКГ, при которой каждый сигнал относится только к одному классу.

В основу задачи классификации ЭКГ-сигналов заложено разделение всех сигналов по типу ритма:

- **Синусовый ритм** — нормальный ритм и его физиологические вариации;
- **Синусовые вариации** — синусовая аритмия, брадикардия, тахикардия и др.;
- **Другой ритм** — предсердный, атриовентрикулярный, идиовентрикулярный и др.

Полученная модель в дальнейшем должна быть интегрирована в SoC-микроконтроллер для локального выделения нозологий на устройстве сбора данных без привлечения персональных компьютеров и серверных мощностей.

## Данные

Обучающая и тестовая выборка сформирована из сигналов открытого датасета **Lobachevsky University Electrocardiography Database (LUDB)**, содержащего 200 аннотированных сигналов ЭКГ.

- Регистрация сигнала: 12 стандартных отведений, частота дискретизации **500 Гц**, длительность **10 секунд**.
- Распределение записей по ритмам:
  - Синусовый ритм: 143
  - Синусовая тахикардия: 4
  - Синусовая брадикардия: 25
  - Синусовая аритмия: 8
  - Нерегулярный синусовый ритм: 2
  - Аномальный ритм: 19

С целью уменьшения размера итоговой модели при формировании выборки выбраны **первое (I) и второе (II) отведение**. С медицинской точки зрения выбранные типы ритма хорошо представлены на графиках данных отведений, поэтому исключение остальных отведений не должно отрицательно сказаться на качестве классификации.

Разделение датасета: **80% обучающей выборки и 20% тестовой** — соответственно 160 и 40 примеров размером `(2 x 5000)`.

## Архитектура нейронной сети

В силу ограниченного объёма оперативной памяти на устройстве в качестве базовой архитектуры выбрана **MobileNetV3 Small**, адаптированная под входные данные в формате `(batch, 2, 5000)`.

Ключевые особенности архитектуры:
- Блоки с **инвертированными остаточными связями (inverted residual)** позволяют сети не разрастаться, сохраняя малое число параметров и компактный размер, что важно при работе на SoC-устройствах.
- Слой **Global Average Pooling** агрегирует временную информацию, делая выход сети инвариантным к локальным сдвигам — сеть концентрируется на наличии паттерна конкретной нозологии в сигнале ЭКГ, а не на его локализации.

Структура сети (схематично):
Input (N, 2, 5000)

→ Conv1d 3x1 (N, 16, 2500)

→ Inverted Residual Block (N, 16, 1250)

→ Inverted Residual Block (N, 24, 625)

→ Inverted Residual Block (N, 24, 625)

→ Inverted Residual Block (N, 40, 313)

→ Inverted Residual Block (N, 40, 313)

→ Conv1d 1x1 (N, 96, 313)

→ Global Avg Pool (N, 96)

→ Linear (96→128) → Linear (128→3)

→ Classifier (N, 3)

## Обучение

- Фреймворк: **PyTorch** (поддержка автоматического дифференцирования, GPU-ускорение).
- Оптимизатор: **Adam** — хорошо справляется с разреженными градиентами в свертках и обеспечивает быструю сходимость на первых эпохах.
- Функция потерь: **CrossEntropy Loss** (комбинация LogSoftmax и Negative Log Likelihood) — лучшая практика при многоклассовой классификации, отсутствие проблемы взрыва/затухания градиента при сохранении интерпретируемости.
- Скорость обучения (Learning Rate): **1e-3** (Adam адаптивно меняет скорость для каждого веса).
- Число эпох обучения при одном испытании оптимизации: **100** с оценкой качества на валидационной выборке.

## Метрика качества

В качестве основной метрики выбрана **макро-усреднённая F1-мера (F1-macro)** — обусловлено необходимостью корректной оценки модели в условиях выраженного дисбаланса, характерного для реальных клинических данных.

В отличие от accuracy, которая при доминировании одного класса может создавать иллюзию высокой эффективности, F1-macro представляет собой гармоническое среднее между полнотой (recall) и точностью (precision), что позволяет одновременно учитывать как пропуски целевых событий (ложноотрицательные ответы), так и ложные срабатывания (ложноположительные ответы). Макро-усреднение нивелирует влияние доминирующего класса и даёт равнозначную оценку вклада каждого типа ритма.

## Оптимизация гиперпараметров

Задача оптимизации гиперпараметров относится к классу задач **глобальной оптимизации с ограничениями**. Целевая функция:
- многоэкстремальная;
- не имеет аналитического описания («чёрный ящик»);
- однократное вычисление требует значительных вычислительных ресурсов (обучение нейросети).

### Варьируемые гиперпараметры

| Гиперпараметр | Диапазон |
|---|---|
| Число классифицирующих нейронов в выходном слое | `f ∈ [80, 200]` |
| Вероятность отключения нейронов (Dropout) | `p ∈ [0.0, 1.0]` |
