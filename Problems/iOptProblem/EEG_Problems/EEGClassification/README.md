## О проекте

Репозиторий содержит реализацию задачи бинарной классификации фрагментов ЭЭГ на предмет наличия эпилептиформной активности. Задача сформулирована в терминах универсального интерфейса `Problem` / `Point` / `FunctionValue`, что позволяет подключать её к внешним фреймворкам глобальной оптимизации (эволюционные алгоритмы, байесовская оптимизация, метаэвристики).

Основная идея — совместно подобрать:

- архитектуру 1D-CNN backbone;
- параметры нечёткого слоя TSK;
- параметры функции потерь и обучения,

максимизируя **MCC** на валидационной выборке.

---

## Решаемая задача

Бинарная классификация ЭЭГ-записей:

| Класс  | Метка | Описание |
|--------|-------|----------|
| `epi`  | `1`   | Фрагмент содержит эпилептиформную активность (приступ / эпилептический паттерн) |
| `norm` | `0`   | Фрагмент соответствует норме (фоновая активность без эпилептических паттернов) |

---

## Практическая значимость

1. **Клиническая диагностика эпилепсии.**
   Визуальный анализ длительных ЭЭГ-записей (десятки минут — часы, десятки каналов) крайне трудоёмок. Автоматическое выделение эпилептических фрагментов:
   - сокращает время разметки;
   - снижает вероятность пропуска коротких приступов;
   - обеспечивает воспроизводимость и объективность оценки.

2. **Мониторинг в реальном времени.**
   Алгоритм пригоден для систем непрерывного мониторинга (ICU, длительный видео-ЭЭГ-мониторинг), где важно оперативно сигнализировать о начале приступа.

3. **Устойчивость к дисбалансу классов.**
   Эпилептические фрагменты встречаются существенно реже нормы. В проекте применяются:
   - `WeightedRandomSampler` для балансировки;
   - `FocalLoss` / `WeightedBCELoss`;
   - метрики, устойчивые к дисбалансу: F1, F-beta, MCC, G-mean, balanced accuracy, recall, specificity (`Metrics.py`).

4. **Интерпретируемость.**
   Нечёткий слой TSK-0/TSK-1 поверх CNN-эмбеддинга даёт «мягкие» правила, что важно в медицинских приложениях, где требуется объяснимость решения.

5. **Гиперпараметрическая оптимизация.**
   Данная задача позволяет автоматически подбирать:
   - параметр `α` focal loss;
   - размерность CNN-эмбеддинга;
   - learning rate для нечёткого слоя;
   - размер backbone-признаков;
   - количество нечётких правил;
   - тип backbone (`simple`, `inception`, `resnet18`, `densenet`).

## Датасет

### Источник и структура

Данные хранятся в `DATA_DIR = 'EEG/learn_dataset'` (см. `EEGClassificationProblem.py`) и организованы по папкам:

```text
learn_dataset/
├── train/
│   ├── epi/   *.npy
│   └── norm/  *.npy
├── val/
│   ├── epi/   *.npy
│   └── norm/  *.npy
├── test/
│   ├── epi/   *.npy
│   └── norm/  *.npy
└── scaler_train.pkl   # сохраняется автоматически при fit
```

Каждый `.npy`-файл — один фрагмент ЭЭГ. Загрузчик `EEGClassificationDataset`:

- автоматически собирает файлы по подпапкам классов (`epi` → метка `1`, `norm` → метка `0`);
- опционально кэширует данные в память (`cache_data=True`);
- нормализует сигнал через `StandardScaler`, обученный только на train и сохраняемый в `scaler_train.pkl`;
- обрезает/центрирует сигнал до `target_length=2560` отсчётов (`_resize_signal`: центр-кроп при большей длине, zero-padding по краям при меньшей);
- применяет аугментации только для train (шум, сдвиг, масштаб, инверсия).

### Параметры сигнала

Пример исследования файла `chb12_06.edf`, датасет CHB-MIT:

| Параметр | Значение |
|----------|----------|
| Частота дискретизации | 256 Гц |
| Длительность исходного EDF-файла | ~3606 сек (~1 час 00 мин 06 сек) |
| Количество отсчётов в файле | 923 136 |
| Количество каналов | 23 ЭЭГ-отведения (из 28 физических записей EDF; 5 служебных `--0…--4` отброшены) |
| Длина одного фрагмента (окна) | 2560 отсчётов = 10 сек при 256 Гц |
| Тип данных | `float64` (до нормализации), значения ~1e-6 … 1.4e-3 В |

### Отведения

Из файла EDF извлекаются 23 канала (стандартная 10–20-система):

```text
FP1-F7, F7-T7, T7-P7, P7-O1,
FP1-F3, F3-C3, C3-P3, P3-O1,
FZ-CZ, CZ-PZ,
FP2-F4, F4-C4, C4-P4, P4-O2,
FP2-F8, F8-T8, T8-P8, P8-O2,
P7-T7, T7-FT9, FT9-FT10, FT10-T8, T8-P8
```

Это соответствует `input_channels=23` в конфигурации модели (`FuzzyCNNConfig.input_channels=23`).

### Классы и баланс

- **epi** — фрагменты с эпилептической активностью (размечаются по аннотациям CHB-MIT: интервалы seizure);
- **norm** — фоновые фрагменты без эпилептической активности.

Точное соотношение классов задаётся на этапе подготовки датасета; в коде предусмотрены:

- `WeightedRandomSampler` с весами `1/class_count` для train;
- `compute_class_weights_from_folders` (в `ThirdPartTools.py`) — для weighted loss;
- выводится статистика: `epi=N, norm=M` при инициализации датасета.

### Как сформирован датасет

1. **Чтение EDF** (`mne.io.read_raw_edf(..., preload=True)`), отбрасывание служебных каналов `--0…--4` и дубликатов `T8-P8`, итого 23 канала.
2. **Окна по 10 сек (2560 отсчётов)** нарезаются по всей записи.
3. **Разметка по аннотациям приступов**: окна, пересекающиеся с интервалами seizure, относятся к классу `epi`, остальные — к `norm`.
4. **Разбиение** на `train / val / test` (стратифицированно, с учётом того, что окна из одной записи не должны «утекать» между сплитами).
5. **Сохранение** каждого окна в отдельный `.npy` в папку соответствующего класса и сплита.
6. **Нормализация** при загрузке: `StandardScaler`, фитимый на train (по всем отсчётам всех каналов) и сохраняемый в `scaler_train.pkl`.

## Архитектура модели

Реализация — `FuzzyPart.py` + `ModelArchitectures.py`.

```text
Input (B, 23, 2560)
   ↓
1D CNN Backbone (simple | deep | inception | resnet18/34/50 | densenet)
   ↓ feature_dim (backbone_feature_dim)
Projection MLP (Linear + BN + ReLU + Dropout) → cnn_embedding_dim
   ↓
FuzzyTSKLayer (num_rules, TSK-0 или TSK-1)
   ↓
Sigmoid → вероятность класса epi
```

Модель возвращает `(output, rule_activations, embedding)`.

Доступные backbone'ы (`ModelFactory.AVAILABLE_MODELS`):

| Имя | Класс | Особенности |
|-----|-------|-------------|
| `simple` | `Simple1DCNN` | 4 сверточных блока, быстрый baseline |
| `deep` | `Deep1DCNN` | 8 сверточных блоков |
| `resnet18/34/50` | `ResNet1D` | Residual-блоки, разная глубина |
| `inception` | `Inception1D` | Параллельные свертки (ядра 3/5/7) |
| `densenet` | `DenseNet1D` | Dense-блоки, параметры `growth_rate`, `n_layers` |

Нечёткий слой (`FuzzyTSKLayer`):

- гауссовы функции принадлежности (`means`, `sigmas` — обучаемые параметры);
- TSK-0: константные выходы правил;
- TSK-1: линейные выходы правил (`rule_weights`, `rule_bias`);
- нормализация активаций правил и взвешенная агрегация.

## Пайплайн обучения

Класс `FuzzyCNNTrainer` в `ThirdPartTools.py`:

- **Loss:** `focal` / `bce` / `weighted_bce`;
- **Optimizer:** `Adam` с раздельными LR для `backbone` / `projection` / `fuzzy_layer`, `weight_decay=1e-5`;
- **Scheduler:** `ReduceLROnPlateau(factor=0.5, patience=5)`;
- **Эпох:** до 100, ранняя остановка (`early_stopping_patience=20`);
- **Gradient clipping:** `max_norm=1.0`;
- **Сохранение:** лучший чекпоинт по `val F1`, логирование `history.json` / `history.csv`;
- **Метрики:** accuracy, precision, recall, specificity, F1, F-beta, MCC, G-mean, balanced accuracy, AUC, TP/TN/FP/FN, class-wise metrics.

Мультипроцессность: поддерживается `gpu_id = ProcRank % GPU_count` (см. `EEGProblem.__init__`).

## Оптимизируемые гиперпараметры

В `EEGProblem.calculate` оптимизируются 6 переменных:

| Переменная | Тип | Диапазон / значения |
|------------|-----|---------------------|
| `focal_alpha` | float | 0.65 – 0.85 |
| `cnn_embedding_dim` | int | 32 – 128 |
| `lr_fuzzy` | float | 1e-3 – 3e-2 |
| `backbone_feature_dim_options` | int | 128 – 1024 |
| `num_rules` | discrete | 8, 12, 16, 20, 24, 32 |
| `backbone_name` | discrete | simple, inception, resnet18, densenet |

Целевая функция:

```python
function_value.value = -trainer.best_val_mcc
```

То есть максимизируется MCC (Matthews Correlation Coefficient) на валидации — метрика, устойчивая к дисбалансу классов и учитывающая все элементы confusion matrix.

## Замечания и ограничения

- **Утечка данных.**
  Окна по 10 сек из одной записи сильно коррелированы. При разбиении необходимо следить, чтобы `train/val/test` формировались по записям / пациентам, а не по отдельным окнам — иначе метрики будут завышены.

- **Дисбаланс.**
  Даже с `WeightedRandomSampler` и focal loss важно контролировать `recall` для класса `epi` — пропуск приступа критичнее ложного срабатывания.

- **Нормализация.**
  `StandardScaler` фитится на всех отсчётах всех train-окон (а не по-канально). Стоит рассмотреть per-channel scaling.

- **Артефакты.**
  В ЭЭГ присутствуют артефакты (моргание, мышечная активность, движение). Аугментации в датасете грубые; для продакшена желательна фильтрация (band-pass 0.5–40 Гц, notch 50/60 Гц).

- **Интерпретируемость TSK.**
  Нечёткие правила интерпретируемы только при низкой размерности `cnn_embedding_dim`. При 64–128 признаков правила теряют «человекочитаемость».
